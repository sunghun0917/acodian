# iBank Semantic Search Query Set

이 문서는 현재 생성된 더미 데이터(`tb_team`, `tb_user_team`, `tb_worklog`, `tb_worklog_status_history`)를 기준으로  
시멘틱 검색 정합성을 점검하기 위한 **샘플 질의문 세트**다.

목표:
- 같은 단어를 직접 쓰지 않아도 유사 업무가 검색되는지 확인
- 선행 TF / 후속 TF 흐름이 연결되는지 확인
- 팀장/사업부장/본부장 관점의 업무가 구분되는지 확인
- 지연 완료, 보류, 재발, 보고 같은 상태 맥락이 검색되는지 확인

재발/유사 업무 연결성을 본다.

   - 기대: 106
2. `이전에 닫았는데 다시 열린 매장 운영 이슈`
   - 기대: 102, 107
3. `예전에 조치했지만 같은 조건에서 다시 흔들린 검색 품질 문제`
   - 기대: 109
4. `작년 같은 시기 운영 안정화 작업과 비슷한 배포 이슈`
   - 기대: 101, 105
5. `이전 업무일지와 표현은 다르지만 같은 문제를 설명하는 건`
   - 기대: 전 팀 공통
6. `후속 TF로 이어진 선행 운영 이슈`
   - 기대: 101→106, 102→107, 103→108, 104→109, 105→110

## 4. Role-based queries

작성자 역할까지 구분되는지 확인한다.

### 4-1. 팀장 관점
1. `팀장이 후속 조치나 승인 여부를 검토한 기록`
   - 기대: 각 팀 lead author worklog
2. `팀장이 일정과 다음 액션을 같이 남긴 업무`
   - 기대: review / verify 성격 worklog
3. `팀장이 보완 요청 관점으로 본 사례`
   - 기대: 101, 104, 109

### 4-2. 사업부장 관점
4. `사업부장이 리스크 보고나 승인 기준을 남긴 업무`
   - 기대: 101, 103, 105, 108, 110
5. `사업부장이 우선순위를 다시 조정한 사례`
   - 기대: 102, 104, 105
6. `고객 영향 때문에 사업부장 검토가 붙은 건`
   - 기대: 102, 107

### 4-3. 본부장 보고 관점
7. `본부장 보고까지 올라갈 정도로 큰 리스크가 있었던 업무`
   - 기대: 101, 103, 105, 109, 110 관련 설명 문맥
8. `경영층 보고용으로 짧게 정리된 운영 이슈`
   - 기대: 105, 110

## 5. Status / deadline queries

상태와 일정 문맥이 검색되는지 본다.

1. `마감일을 넘겨서 완료된 업무`
   - 기대: `COMPLETED` + completion_date > due_date
2. `진행하다가 외부 확인 때문에 멈춘 일`
   - 기대: `ON_HOLD`
3. `시작은 했지만 아직 닫지 못한 업무`
   - 기대: `IN_PROGRESS`
4. `우선순위가 바뀌어서 취소된 업무`
   - 기대: `CANCELLED`
5. `지금은 미완료인데 나중에 다시 봐야 하는 작업`
   - 기대: `PENDING`, `ON_HOLD`
6. `마감이 촉박해서 급한 대응으로 올라온 건`
   - 기대: `URGENT`, `HIGH`

## 9. Evaluation recipe

각 질의문에 대해 아래를 체크한다.

### Precision-oriented
- 상위 5개 결과 중 기대 팀 문서가 몇 개 포함되는가
- 전혀 무관한 팀이 얼마나 섞이는가

### Semantic-oriented
- 같은 단어를 직접 안 썼는데도 기대 팀/업무가 나오는가
- 후속 TF가 선행 TF와 함께 검색되는가
- 역할(팀장/사업부장/본부장) 차이가 결과 문맥에 보이는가

### Temporal-oriented
- 재발/후속/과거 유사 업무 질의에서 날짜 흐름이 자연스러운가
- 지연 완료, 보류, 취소 문맥이 상태 질의에 맞게 검색되는가

1. `야간 배치가 겹치면서 운영이 흔들린 사례`

4. `3개월 전 비슷한 재고 불일치 대응`
5. `이전에 닫았는데 다시 열린 운영 이슈`
6. `팀장이 후속 조치까지 같이 검토한 기록`
7. `사업부장이 리스크를 보고 승인 기준을 남긴 업무`
8. `임베딩 품질과 RAG 응답 흔들림을 같이 본 실험`
9. `릴리즈 트레인 결과가 대시보드 보고로 이어진 흐름`
