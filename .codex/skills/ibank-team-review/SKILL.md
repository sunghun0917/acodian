# iBank Team Review

## Required assets

- designated team lead persona file
- `.codex/templates/team-lead-worklog-review-checklist.md`

## What to do

1. Review from the specific team lead's perspective
2. Check team fit, role fit, timing, dependency, and collaboration quality
3. Return:
   - approve
   - request revision
   - reject

## Input shapes

- a few worklogs pasted into chat
- a batch of generated worklogs
- SQL rows that need human-style validation comments
