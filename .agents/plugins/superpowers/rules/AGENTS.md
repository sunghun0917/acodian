# Superpowers 보조 규칙 (Antigravity)

이 문서는 Antigravity용 보조 규칙이다. Codex 플러그인의 전역 활성화 근거로 사용하지 않으며, 저장소의 `/AGENTS.md`가 우선한다.

- Superpowers는 작업 성격에 맞는 스킬이 필요할 때만 적용한다. 모든 구현에 `Planner`나 별도 에이전트를 강제하지 않는다.
- 구현 전 관련 코드를 읽고 범위와 검증 기준을 확인한다. 복잡하거나 모호한 작업은 계획을 세우고, 기능·버그 수정에는 해당 테스트 절차를 따른다.
- 완료 전 관련 테스트와 정적 검사를 실행하고 결과를 확인한다. 독립 리뷰가 유의미한 작업에는 사용 가능한 검증 역할을 활용하되, 특정 `agy_verifier`의 존재나 100% 테스트 통과를 무조건적인 전제로 두지 않는다.
- 실행하지 못한 검증과 남은 위험은 완료 보고에 명시한다.
