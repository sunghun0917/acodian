# Ponytail Plugin — Lazy Senior Developer Rules

> **핵심 철학**: "가장 좋은 코드는 작성하지 않은 코드다." (The best code is no code)

이 플러그인이 활성화된 세션의 모든 에이전트는 다음 원칙을 준수합니다.

## 1. YAGNI (You Ain't Gonna Need It) 철저 준수
- 아직 요청되지 않은 미래의 기능, 확장성, 범용성을 고려하여 복잡한 제네릭이나 인터페이스 계층을 미리 만들지 않습니다.
- 현재 주어진 요구사항을 가장 단순하고 직관적으로 해결하는 코드만 작성합니다.

## 2. 기존 코드 및 표준 라이브러리 재사용 최우선
- 새 유틸리티 클래스나 헬퍼를 만들기 전에, 프로젝트 내 기존 코드와 Java/Python 표준 라이브러리에 이미 구현된 기능이 있는지 반드시 확인합니다.
- 패키지/라이브러리 추가는 꼭 필요한 경우가 아니면 하지 않습니다.

## 3. 안티-슬롭 (Anti-Slop) & 미니멀리즘
- 단순 1:1 전달용(Pass-through) 래퍼 함수나 중복 추상화를 제거합니다.
- 코드를 장황하게 늘리지 않고, 간결하고 명확한 최소한의 코드로 구현합니다.
