# V3: ID 없는 순수 자연어 질문 50문항 벤치마크

> **핵심 요약**: V2의 200건 업무일지와 등록 관계를 기반으로 하되, **질문에서 업무·작성자·팀 ID나 ID 출력 요청을 완전히 배제한 순수 자연어 질의 평가 세트**입니다. 실제 검색과 답변 생성 단계에는 `benchmark-v3.jsonl`의 `question` 텍스트만 전달됩니다.

---

## 📊 1. 문항 구성

| 질의 유형 | 문항 수 | 설명 |
| :--- | :---: | :--- |
| **단순 사실** | 10 | 단일 본문 내 구체적 사실 질의 |
| **직접 관계** | 12 | 대상 업무의 작성자, 소속 팀, 직접 선행업무 질의 |
| **다중 관계** | 14 | 선행업무의 작성자/소속 팀 등 2단계 이상 의존관계 질의 |
| **전체 선행 탐색** | 8 | 코퍼스 내 직·간접 선행업무 전체 탐색 |
| **관계 부재** | 6 | 등록된 선행업무가 없는 업무에 대한 질의 (검증된 부재) |
| **합계** | **50** | **Development 25문항 / Evaluation 25문항** 분할 |

- **자연어 질문 구성**: 기존 V2 질문에서 ID만 제거한 질문 30건, 제목을 의역한 질문 14건, 본문의 식별 단서를 의역한 질문 6건 포함.
- **식별성 검증**: 본문 단서는 비공개 정답 파일의 `anchor_evidence`와 원천 SQL 본문을 엄격히 대조하여 검증.
- **컴포넌트 분할**: 시작 업무 27개와 22개 의존관계 컴포넌트로 구성되며, 동일한 컴포넌트가 development와 evaluation 양쪽에 중복 배치되지 않도록 격리.

## 💻 2. 재현 및 정적 검사

저장소 루트에서 실행합니다:

```powershell
# 1. 벤치마크 무결성 검사
ai/.venv/Scripts/python.exe -B -X utf8 docs/ai/evaluation/v3/build_benchmark.py --check

# 2. 단위 회귀 테스트 실행
ai/.venv/Scripts/python.exe -B -X utf8 -m unittest discover -s docs/ai/evaluation/v3 -p 'test_*.py' -v
```

> [!NOTE]
> 원천 V2 데이터셋을 의도적으로 변경하고 V3를 새로 생성할 때만 `--check` 옵션 없이 실행합니다.

## 🎯 3. 채점 경계 및 원칙

V3는 사용자의 자연어 입력으로부터 **시작 업무 식별**과 **관계 탐색**을 동시에 평가합니다:

- **다면적 집계**: 결과는 `시작 업무 식별`, `관계 방향 및 경로`, `최종 업무/작성자/팀`, `전체 선행업무 집합`, `검증된 부재`, `모호성 처리`로 세분화하여 집계합니다.
- **문자열 정오 판정 배제**: 질문에 ID를 요구하지 않았으므로, 답변 텍스트 내 숫자 유무만으로 정오를 판정하지 않고 비공개 `structured_gold`와 대조합니다.
- **범위 제한**: 전체 선행업무와 관계 부재의 정답은 **고정 200건 유도 부분그래프 기준**입니다.
