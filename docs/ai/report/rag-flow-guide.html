등록 흐름

원본 + 등록 Outbox 커밋 → 워커 선점 → AI 직접 색인 → 성공 기록·재시도

등록 전용 Outboxtb_worklog_ai_post_process_outbox에 입력과 성공 단계를 보존합니다. 성공한 색인은 자동 재시도에서 반복하지 않습니다.

색인 경로만 표시다른 등록 후처리와 추가 요청 상세는 생략했습니다. 실제 제품 동작은 변경하지 않았습니다.

전체 결과로 완료 판정색인 성공은 해당 단계의 성공 기록입니다. Outbox 제거와 결과 알림은 전체 등록 후처리 결과를 기준으로 처리합니다.

수정 흐름

DB 수정 + Outbox 기록 → 워커 선점 → AI에서 기존 문서 삭제·재색인 → 완료·재시도

삭제 흐름

DB 소프트 삭제 + Outbox 기록 → 워커 선점 → AI에서 팀·전역 문서 삭제 → 완료·재시도

그래프는 가로로 밀어서 볼 수 있습니다. 각 선의 화살표 방향을 따라 읽어주세요.

W는 업무 전체, S는 각 변경 단계W는 획득부터 해제까지 유지합니다. S는 해당 단계마다 획득·해제하며, snapshot·schema 게시 전체에 유지되는 락이 아닙니다.

AI 락은 프로세스 내부용W·S는 같은 이벤트 루프에서만 공유됩니다. 원본 DB의 @Version, Outbox의 선점·lease와는 다른 보호 장치입니다.

현재 구현의 실행·복구 경로인덱싱 설정 활성화 기준이며 운영 부하는 측정하지 않았습니다. 재색인 삭제 실패는 해당 문서의 삽입을 중단합니다.
