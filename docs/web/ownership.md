# 프론트엔드 담당 범위

프론트엔드 개발자의 현재 담당 범위를 정리하는 문서다.

## 작성 규칙

- 작업 시작 전에 업데이트한다.
- 담당자가 바뀌면 바로 수정한다.
- 공통 영역은 단독 소유보다 `공동`으로 표시하고, 실제 수정 담당자를 메모에 남긴다.
